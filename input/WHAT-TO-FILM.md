# What to film (so Omni has something to transform)

Omni is **video-to-video** — it changes footage you already have. You don't need a studio; a phone is fine. Shoot 10–15s clips, good light, and *perform the real action* — Omni transforms what's actually there.

| If you want… | Film this |
|---|---|
| Product swap | You slowly rotating a **plain can / box / bottle** in hand |
| Material morph | You rotating a **plain mug** on a table (with a reflective surface) |
| Set transform | Any **talking-head** clip (no special shoot) |
| Self restyle (clay/anime) | Clean **talking-head**, even light |
| Holograms / particles | You **gesturing at empty air** (cup a hand, point) |
| Logo wrap | You slowly turning a **blank card / laptop lid** (partial turn) |
| Physics hook | You tilting an **empty glass**, or holding out an object |

Tips: fill the frame with the action · move slowly (fast motion loses tracking) · keep the thing you'll change unobstructed · one clip per effect. Drop the mp4s here in `input/`.
